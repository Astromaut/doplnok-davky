# 🎈 Doplnok dávky rádioterapie

### Čo to je?

Táto aplikácia pomáha vypočítať navýšené a/alebo doplnené frakcie pre prípady kedy je rádioterapia z rôznych dôvodov prerušená, aby sa tak prispelo k zachovaniu biologického účinku pôvodne zamýšľanej rádioterapie.

Je založená na báze LQ modelu s akcelerovanou repopuláciou -
ref: [Dale et al. (2002)](https://pubmed.ncbi.nlm.nih.gov/12555877/).

Návod na použitie nájdete [tu](https://github.com/Astromaut/doplnok-davky/blob/main/navod.pdf).


### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
